## 1. Initial Findings (Before Cleanup)

1. **Unoptimized Remote Images:**
   - `<Image>` components across [VehicleCard.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/cars/VehicleCard.tsx), [CarDetailsView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/cars/CarDetailsView.tsx), [app/page.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/app/page.tsx), and [Header.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/layout/Header.tsx) had `unoptimized={true}` hardcoded or lacked responsive `sizes` definitions.
   - This bypassed the Next.js image optimization pipeline, forcing browsers to download raw multi-megabyte JPEG images from Unsplash at full camera sensor dimensions instead of modern WebP/AVIF images scaled to the viewport.
2. **Duplicate Code Directory (`src/`):**
   - An entire redundant `src/` tree existed (`src/components/`, `src/lib/`) containing 13 stub files whose sole purpose was re-exporting modules from root directories (`components/`, `lib/`).
   - Nothing in `app/`, `components/`, `lib/`, or `scratch/` imported from `src/`. However, TypeScript's `include: ["**/*.ts", "**/*.tsx"]` in `tsconfig.json` was compiling all 13 duplicate stub files on every build.
3. **Unused Starter Assets (`public/`):**
   - Default boilerplate SVG files (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`) generated by `create-next-app` were present in `public/` but had zero references in the application.
4. **Infinite Re-render Loop & Depth Exceeded Error:**
   - In [RenterDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/RenterDashboardView.tsx), [app/dashboard/page.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/app/dashboard/page.tsx), [CheckoutView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/checkout/CheckoutView.tsx), and [BookingDetailView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/bookings/BookingDetailView.tsx), `useSyncExternalStore`'s `getSnapshot` functions were calling `getBookings()`, `getCars()`, and `getCurrentSession()` directly on every render tick.
   - Because `getCurrentSession()` executed `JSON.parse()` on every call and `getBookings()` returned a fresh array reference, React detected `Object.is(prevSnapshot, newSnapshot) === false` continuously, triggering `Maximum update depth exceeded` and the runtime warning: *"The result of getSnapshot should be cached to avoid an infinite loop"*.
5. **Unused Imports & ESLint Warnings:**
   - Unused imports in `app/page.tsx`, `app/dashboard/page.tsx`, `BookingDetailView.tsx`, `TripTrackingView.tsx`, `CheckoutView.tsx`, and `RenterDashboardView.tsx` generated ESLint linter noise.

## 2. Changes Made & Files Modified/Removed

### 2.1 Next.js Image Optimization Pipeline
- **[next.config.ts](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/next.config.ts):**
  - Added `formats: ['image/avif', 'image/webp']` to `images` configuration.
  - Next.js now negotiates modern, high-compression AVIF and WebP formats automatically when supported by the client browser.
- **[components/cars/VehicleCard.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/cars/VehicleCard.tsx):**
  - Enabled Next.js optimization for all Unsplash and local catalogue images using `unoptimized={!isOptimizable}`.
  - Specified exact responsive sizes: `sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 33vw"`.
- **[components/cars/CarDetailsView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/cars/CarDetailsView.tsx):**
  - Enabled Next.js optimization across the 4-tile gallery mosaic, host avatar, contact dialog, and full-screen lightbox modal.
  - Main hero photo configured with `priority` and responsive `sizes="(max-width: 1024px) 100vw, 66vw"`.
  - Secondary tiles configured with `sizes="(max-width: 1024px) 50vw, 33vw"`.
  - Lightbox thumbnails configured with `sizes="64px"`.
- **[app/page.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/app/page.tsx):**
  - Enabled Next.js optimization on the hero visual articulation.
  - Added `sizes="(max-width: 1024px) 100vw, 42vw"` and `priority` to accelerate Largest Contentful Paint (LCP) on the landing page.
- **[components/layout/Header.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/layout/Header.tsx):**
  - Enabled Next.js image optimization for user profile avatar (`width={28}`, `height={28}`).

### 2.2 Storage Snapshot Reference Caching (Infinite Loop Fix)
- Replaced direct storage parsing inside `getSnapshot` with raw-string reference caching in:
  - **[components/dashboard/RenterDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/RenterDashboardView.tsx)**: cached `cachedBookingsRaw`, `cachedCarsRaw`, `cachedSessionRaw`.
  - **[app/dashboard/page.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/app/dashboard/page.tsx)**: cached `cachedSessionRaw`.
  - **[components/checkout/CheckoutView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/checkout/CheckoutView.tsx)**: cached `cachedCarsRaw`, `cachedSessionRaw`.
  - **[components/bookings/BookingDetailView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/bookings/BookingDetailView.tsx)**: cached `cachedBookingsRaw`, `cachedCarsRaw`, `cachedSessionRaw`.
  - **[components/bookings/TripTrackingView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/bookings/TripTrackingView.tsx)**: cached `cachedBookingsRaw`, `cachedCarsRaw`, `cachedSessionRaw`.
- **Outcome:** If storage contents have not changed, `useSyncExternalStore` receives the identical memory reference, completely eliminating redundant re-renders and preventing the React 19 maximum update depth warning.
