## 1. Initial Findings (Before Cleanup)

1. **Unoptimized Remote Images Across Dashboards and Subviews:**
   - `<Image>` components across [HostFleetDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/HostFleetDashboardView.tsx) had `unoptimized` hardcoded across 5 key photo locations (fleet list cards, pending booking preview, vehicle breakdown table, booking modal preview, and listing creator presets).
   - This bypassed the Next.js image optimization pipeline, forcing browsers to download raw multi-megabyte JPEG images from Unsplash at full sensor dimensions instead of modern WebP/AVIF images scaled to the viewport.
   - [AdminModerationDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/AdminModerationDashboardView.tsx), [RenterDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/RenterDashboardView.tsx), [BookingDetailView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/bookings/BookingDetailView.tsx), and [CheckoutView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/checkout/CheckoutView.tsx) were missing safety guards for non-Unsplash custom URLs, and the dispute thumbnail in the admin moderation dashboard was missing responsive `sizes` definitions.
2. **Duplicated Optimization Helper Logic:**
   - Ad-hoc URL pattern checks (`startsWith('/') || includes('images.unsplash.com')`) were duplicated across individual component files rather than shared from the data/storage layer.
3. **Duplicate Code Directory (`src/`):**
   - An entire redundant `src/` tree existed (`src/components/`, `src/lib/`) containing 13 stub files whose sole purpose was re-exporting modules from root directories (`components/`, `lib/`). TypeScript's `include: ["**/*.ts", "**/*.tsx"]` in `tsconfig.json` was compiling all 13 duplicate stub files on every build.
4. **Unused Starter Assets (`public/`):**
   - Default boilerplate SVG files (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`) generated by `create-next-app` were present in `public/` but had zero references in the application.
5. **Infinite Re-render Loop & Depth Exceeded Error:**
   - In [RenterDashboardView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/dashboard/RenterDashboardView.tsx), [app/dashboard/page.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/app/dashboard/page.tsx), [CheckoutView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/checkout/CheckoutView.tsx), and [BookingDetailView.tsx](file:///c:/Users/DELL/Documents/IBT/sq2-daniel-basaznew/module-03-react-nextjs/Projects/shegger-wheels/components/bookings/BookingDetailView.tsx), `useSyncExternalStore`'s `getSnapshot` functions were calling `getBookings()`, `getCars()`, and `getCurrentSession()` directly on every render tick.
   - Because `getCurrentSession()` executed `JSON.parse()` on every call and `getBookings()` returned a fresh array reference, React detected `Object.is(prevSnapshot, newSnapshot) === false` continuously, triggering `Maximum update depth exceeded` and the runtime warning: *"The result of getSnapshot should be cached to avoid an infinite loop"*.
6. **Unused Imports & ESLint Warnings:**
   - Unused imports across dashboard and booking views generated ESLint linter noise.
